Introduction

Welcome to the Axon documentation. Axon is a decentralized privacy infrastructure designed to provide secure, anonymous networking for everyone.

Getting Started

To start using Axon, you can download the client for your platform or use the CLI for advanced configuration.

bash
$ axon init

API Reference

The following endpoints allow nodes to register, send heartbeats, and fetch healthy nodes from the network.

POST/api/v1/registry

Registers or unregisters a proxy node in the Axon network. When registering (status: 1), the server responds with a 202 Accepted and asynchronously contacts the node to verify its identity.

Payload (JSON)

json
{
  "port": "number",
  "status": "number (1 to register, 0 to unregister. Note: node_id is required if status is 0)"
}

POST/api/v1/heartbeat

Nodes must continuously ping this endpoint to prove they are alive. The node must provide the secret key it received during the asynchronous verification challenge.

Headers

http
Authorization: Token <your-secret-key-received-from-registry>

GET/api/v1/nodes

Retrieves a list of all currently active and healthy proxy nodes in the network.

Response (JSON)

json
{
  "status": 1,
  "data": {
    "nodes": [
      {
        "node_id": "string",
        "ip": "string",
        "port": 8080
      }
    ]
  },
  "error": null
}
