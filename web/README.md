# Axon Landing Page

This is the public-facing marketing and landing website for **Axon**, a decentralized privacy infrastructure.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS 4
- **Animations**: GSAP
- **Components**: shadcn/ui
- **Icons**: Lucide Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Design Philosophy
The design follows a premium cybersecurity startup aesthetic with:
- Dark Mode by default
- Glassmorphism UI elements
- Neon glow effects (Electric Blue, Purple Neon, Cyan)
- Futuristic networking visuals
- Smooth GSAP-powered transitions and scroll animations
